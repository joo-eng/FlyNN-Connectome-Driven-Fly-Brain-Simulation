# FlyNN-Connectome-Driven-Fly-Brain-Simulation
FlyNN is a fly brain simulation driven by the real Drosophila connectome, not scripted AI. I extracted and validated a ~1,300-neuron subcircuit (looming detection, courtship pursuit, escape, steering) from the male CNS dataset. Runs standalone with a sensory-in/motor-out interface; first application is a multiplayer Roblox world.
